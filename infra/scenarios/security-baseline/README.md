# NSG ＆ UDR セキュリティポリシーシナリオ

## 概要

このシナリオは、**NSG（ネットワークセキュリティグループ）と UDR（ユーザー定義ルート）を使用したセキュアなVNet構成** のデモンストレーションです。

## 用途

- セキュリティベースライン設定のテスト
- エグレスフィルタリング（デフォルトルート制御）
- NSG ルールのベストプラクティス確認

## 構成

```
┌────────────────────────────────────────────────┐
│        VNet (10.50.0.0/16)                     │
│   ┌──────────────────────────────────────┐    │
│   │  Secure-App Subnet (10.50.1.0/24)    │    │
│   │                                      │    │
│   │  ┌──────────────────────────────┐    │    │
│   │  │ NSG Rules                    │    │    │
│   │  │ - Deny RDP (3389) ❌         │    │    │
│   │  │ - Deny SSH (22) ❌           │    │    │
│   │  │ - Allow VNet ✅              │    │    │
│   │  └──────────────────────────────┘    │    │
│   │                                      │    │
│   │  ┌──────────────────────────────┐    │    │
│   │  │ Route Table (UDR)            │    │    │
│   │  │ - Default 0.0.0.0/0          │    │    │
│   │  │   → Next Hop: 10.50.0.4      │    │    │
│   │  │   (Virtual Appliance)        │    │    │
│   │  └──────────────────────────────┘    │    │
│   └──────────────────────────────────────┘    │
└────────────────────────────────────────────────┘
```

## リソース

| リソースタイプ | 個数 | 説明 |
|---|---|---|
| Network Security Group (NSG) | 1 | インバウンド拒否ルール（RDP, SSH） |
| Route Table (UDR) | 1 | デフォルトルート → 仮想アプライアンス |
| Virtual Network | 1 | セキュアサブネット |

## セキュリティルール

### NSG インバウンドルール

| 優先度 | ルール | アクション | 説明 |
|---|---|---|---|
| 200 | deny-inbound-rdp | Deny | RDP (3389) を拒否 |
| 210 | deny-inbound-ssh | Deny | SSH (22) を拒否 |
| 300 | allow-vnet-inbound | Allow | VNet 内通信を許可 |

## デプロイ方法

```bash
az deployment group create \
  --resource-group myResourceGroup \
  --template-file infra/scenarios/security-baseline/bicep/main.bicep \
  --parameters scenarioCode=csa01 location=southwestasia
```

## 主要パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| `scenarioCode` | `csa01` | リソース名プレフィックス |
| `location` | `southwestasia` | デプロイリージョン |

## ユースケース

- **エンタープライズセキュリティ**: RDP/SSH ブロックの実装
- **コンプライアンス**: セキュリティベースライン準拠の検証
- **ハイブリッドアーキテクチャ**: 中央のセキュリティアプライアンスへのトラフィック集約
- **ゼロトラスト**: 直接アクセス禁止 → 仮想アプライアンス経由のみ

## 注意事項

- `nextHopIpAddress: 10.50.0.4` は仮想アプライアンス（ファイアウォール等）のIPアドレスです
- 実際のデプロイでは、このアドレスを環境に合わせて変更してください
